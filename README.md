# Portfolio

Personal portfolio website built with React 19, TypeScript, and Vite to showcase my expertise in Web Development through building a Personal Website.

## Tech Stack

**Core:** React 19 · TypeScript · Vite 8 · React Router 7  
**Styling:** Tailwind CSS v4 · Google Fonts
**3D:** Three.js · @react-three/fiber · @react-three/drei  
**Icons:** Font Awesome 7  
**Animations:** motion (Framer Motion)  
**Tooling:** ESLint · Prettier · Husky · lint-staged

## Pages

| Route         | Content                                            |
| ------------- | -------------------------------------------------- |
| `/`           | Hero with 2D SVG or interactive 3D FRV logo        |
| `/about`      | Personal info rendered as a JSON block + portrait  |
| `/experience` | Filterable tech stack grid + work history timeline |
| `/projects`   | Project showcase with screenshots & GitHub links   |

## Scripts

```bash
npm run dev       # Start dev server (HMR)
npm run build     # Type-check + production build
npm run preview   # Preview production build
npm run lint      # ESLint
npm run format    # Prettier
```
